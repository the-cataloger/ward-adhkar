# وِرد | Ward ✨

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لأذكار الصباح والمساء. واجهة عربية من اليمين إلى اليسار، بطابع داكن أخضر/ذهبي، دون إعلانات أو اتصال بالإنترنت.

## مزايا الإصدار 1.1
- عدّاد كبير لكل ذكر وحفظ التقدم يوميًا محليًا.
- البحث داخل نصوص الأذكار والمصادر، وإضافة الأذكار إلى المفضلة.
- نسخ الذكر ومشاركته مع التخريج.
- تكبير وتصغير الخط، والتحكم بالاهتزاز والانتقال التلقائي.
- ملخص إنجاز يومي وسجل نشاط الأسبوع الماضي.
- تنبيهات صباحية ومسائية بمواعيد قابلة للتعديل، وإعادة جدولتها بعد تشغيل الجهاز.
- إشعارات محلية، وتخطي تنبيه الفترة المكتملة في يومها.

## بناء التطبيق
افتح المشروع في **Android Studio** وأجرِ Gradle Sync، ثم Build > Build APK(s).
أو انتقل إلى **Actions** في GitHub لتنزيل APK التجريبي بعد نجاح **Android APK**.

**الحد الأدنى:** Android 8 (API 26). **الهدف:** Android 15 (API 35).

## حدود مهمة
- إشعارات Android تعمل بجدولة غير دقيقة `setAndAllowWhileIdle`؛ قد يؤخرها توفير البطارية. لا يطلب التطبيق صلاحية المنبهات الدقيقة.
- المواعيد ثابتة بتوقيت الهاتف، ولا تستند حاليًا إلى الشروق والغروب أو تحديد الموقع.
- النصوص والمصادر واردة في ملف `app/src/main/assets/adhkar.json`؛ **قبل النشر العام** يلزم تدقيق علمي مستقل للألفاظ والتخريج والأحكام على الروايات، ولا يجوز اعتبار قائمة المصادر توثيقًا محكّمًا مكتملًا.
- لا توجد أذونات إنترنت أو تحليلات أو إرسال للبيانات. العدّ والمفضلة والإعدادات محفوظة على الجهاز.
